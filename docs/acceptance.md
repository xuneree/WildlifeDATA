# 模块1如何验收

本次交付对应需求V1.2 §3.1，相机位点、工作周期、维护与数据回收。

## 先获取可运行代码

在本交付分支的 GitHub 页面点 **Code → Download ZIP**，解压后进入包含 `compose.yaml` 的项目根目录。

源码包内的 [acceptance.html](acceptance.html) 是带截图的完整说明；解压后可双击在浏览器打开。它是操作说明，系统需要按下面的步骤启动。[验收清单CSV](模块1验收清单.csv) 可以用Excel或Numbers填写结果。

## 启动系统

Mac：安装并运行Docker Desktop，在终端操作。Dell Windows：Docker Desktop启用WSL2，在WSL终端操作。需要可用的 `docker compose` 和 `python3`，首次启动会下载容器镜像与依赖。

在解压后的项目根目录执行：

```bash
python3 scripts/create-local-env.py
docker compose up -d --build --wait
```

服务就绪后，在**运行Docker的这台电脑**浏览器打开：

http://127.0.0.1:8080

用户名默认为 `admin`。密码是本机新生成的隐藏文件 `.env` 中 `ADMIN_PASSWORD=` 后面的内容。Mac可按Command+Shift+.显示隐藏文件。不要把.env或密码发到聊天中。

本下载包没有云端账号、令牌或真实数据库。请先用新建的空白测试环境和下面的合成数据。已有部署先备份并保留原.env；脚本会保留已有.env，不会重置已有管理员密码。

当前会话尚无可直接访问的云端试用链接；云环境的127.0.0.1不能从你的本机直接打开。不希望本机部署时，请先反馈需要的试用方式；无需在打不开页面的情况下验收。
