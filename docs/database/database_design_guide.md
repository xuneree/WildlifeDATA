2026-11-06 设计补充：

维护统一使用标准英文 maintenance，维护类型为安装 install、回收 collect、停用 deactivate；回收仅为维护类型，不另设并列业务实体。布设周期引用起始、结束维护，媒体来源引用实际取得数据的维护。

一期不单独建立独立事件及成员表。在媒体层保存是否独立拍摄，NULL 表示未判定，不等于否。多物种文件采用 media_species 中的物种级标记计算物种独立拍摄次数及 RAI，避免单一文件标记漏计后来出现的其他物种；具体规则、失效重算及筛选边界见数据库设计 V1.5。

生境、地形等固定选项直接保存为 location 字段，由统一版本化选项配置和数据库 CHECK 校验，一期不分别建字典表。

个体代表图增加角度和部位，如左侧/右侧/正面/背面-全身/脸/尾/左前肢/右前肢/左后肢/右后肢等，默认角度为多角度，默认部位为全身，用来导入拼合图

将账号表和授权表拆开，账号表中只区分管理员和普通用户，管理员即全局管理员，可授权区域管理员，并具有所有区域的管理权限；普通用户可能在不同区域/项目具备不同的权限，权限等级有四种：管理/工作/只读/无，区域层级有管理权限，项目层级无管理权限，由区域管理员进行授权，区域权限覆盖项目权限，项目权限可高于区域权限，如区域已开通工作权限，对所有项目都具有工作权限，如区域是已读/无权限，可单独在项目开通工作权限；
