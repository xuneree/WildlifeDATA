### 业务对象
| keyword | 中文名 | 定义 |
| --- | --- | --- | 
| group | 工作组 | 独立管理数据的工作组，如山西、西北、河北&北京（写死） |
| project | 项目 | 有明确目标的监测项目，挂靠group，如和顺常规监测、和顺X337 |
| location | 位点 | 地理上一个监测位置，挂靠group，可关联多个project，如701 |
| camera | 相机 | 位点内的机位编号，非实体设备，挂靠location，如701A、701B |
| maintenance | 维护 | 对机位的一次现场维护，分安装、回收、停用三类，挂靠camera |
| deployment | 布设 | 机位两次维护之间的布设周期，首次从安装开始，挂靠camera |
| media | 媒体文件 | 相机在某个布设周期中拍摄的媒体文件，挂靠deployment |
| annotation | 标注 | 关联media与species或individual的标注信息 |
| species | 物种 | 全系统通用的物种字典 |
| individual | 个体 | 每只豹/兔狲个体的档案信息 | 

### 基础数据表（一期）
| 底表 | 中文名 | 主要字段 |
| --- | --- | --- |
| project | 项目信息表 | 项目编号、区域、项目名称、项目类型、备注*、负责人 |
| project_location | 项目-位点关联表 | 项目编号、位点编号 |
| location | 位点表 | 位点编号、历史编号*、布设类型、区域、项目、经度、纬度、海拔、生境类型、地形、停启用状态、轨迹文件* |
| location_habitat | 位点生境表 | 植被信息、动物痕迹、人为干扰（记录会经常变化的生境信息，区别于位点表保存不变的信息） |
| camera_maintenance | 相机维护记录表 | 维护日期、位点编号、相机编号、维护类型（安装/回收/停用）、维护批次、相机型号（维护后的）、相机参数（维护后的）、相机工作状态、异常问题*、维护内容* |
| camera_deployment | 布设周期表 | 位点编号、相机编号、起始维护id、结束维护id、相机型号、布设日期、结束维护日期、有效工作开始日期、有效工作结束日期、时间校准*（加或减xxx秒，对该周期内所有媒体生效）|
| media | 媒体文件表 | 文件名称、文件类型、存储路径、维护批次、拍摄时间、校准时间*、是否独立拍摄*（以及其他基础信息）|
| media_derivative | 代理视频与预览图 | 媒体文件id、派生文件类型、派生文件名、存储路径 |
| media_species | 媒体文件-物种关联表 | 媒体文件id、物种id、标注人、复核状态、复核人、导入记录id、该物种是否独立拍摄* |
| media_individual | 媒体文件-个体关联表 | 媒体文件id、个体id、标注人、复核状态、复核人、导入记录id |
| media_tag | 媒体文件-素材标签关联表 | 媒体文件id、标签id、标记人、素材描述* |
| species | 物种字典 | 物种id、物种代码、物种名称、拉丁学名* |
| individual | 个体档案表 | 个体id、当前编号、物种id、代表图id*、性别、出生年份、推测出生日期下界*、推测出生日期上界*、存活状态、建档时间 |
| individual_profile | 个体代表图 | 个体id、角度、部位、图片名称、存储路径 |
| individual_alias | 个体历史编号表 | 个体id、历史编号、停用时间* |
| user | 平台账号表 | 用户id、登录名、密码、账号类型（管理员/普通用户） |
| user_permission | 账号权限表 | 用户id、工作组-权限、项目-权限、精准坐标权限、数据下载权限 |


备注：*表示非必填，以上只列了主要字段，根据需求补充id、时间等必要字段


2026-11-06 设计补充：
一期暂时不加个体关系；
个体代表图增加角度和部位，如左侧/右侧/正面/背面-全身/脸/尾/左前肢/右前肢/左后肢/右后肢等，默认角度为多角度，默认部位为全身，用来导入拼合图；
将区域修改为工作组，是数据归属和人员权限管理的单位；
账号表中区分系统管理员和普通用户，系统管理员授权工作组的管理员，工作组管理员对工作组内的项目和人员权限进行管理。
账号注册时申请加入工作组以及权限等级（管理/工作/只读），工作组管理员进行审批。




即全局管理员，可授权区域管理员，并具有所有区域的管理权限；普通用户可能在不同区域/项目具备不同的权限，权限等级有四种：管理/工作/只读/无，区域层级有管理权限，项目层级无管理权限，由区域管理员进行授权，区域权限覆盖项目权限，项目权限可高于区域权限，如区域已开通工作权限，对所有项目都具有工作权限，如区域是已读/无权限，可单独在项目开通工作权限；
