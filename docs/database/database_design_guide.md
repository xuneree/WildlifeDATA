### 业务对象
| keyword | 中文名 | 定义 |
| --- | --- | --- | 
| group | 工作组 | 独立管理数据的工作组，如山西、西北、河北&北京 |
| project | 项目 | 有明确目标的监测项目，挂靠group，如和顺常规监测、和顺X337 |
| location | 位点 | 地理上一个监测位置，挂靠group，可关联多个project，如701 |
| camera | 相机 | 位点内的机位编号，非实体设备，挂靠location，如701A、701B |
| operation | 相机操作 | 对机位的一次现场操作，分安装/检查/撤回等不同类型，挂靠camera |
| deployment | 布设 | 机位两次维护之间的布设周期，首次从安装开始，挂靠camera |
| media | 媒体文件 | 相机在某个布设周期中拍摄的媒体文件，挂靠deployment |
| annotation | 标注 | 关联media与species或individual的标注信息 |
| species | 物种 | 全系统通用的物种字典 |
| individual | 个体 | 每只豹/兔狲个体的档案信息 |

备注：
1.*表示非必填;
2.以上只列了主要字段，根据需求补充id、时间等必要字段;
3.生境信息表用于记录会经常变化的生境信息，区别于位点表保存相对不变的信息；
4.相机操作记录表中，相机参数在初始设置时有一套默认设置，只有在变更时才记录相机参数；

权限及数据规则补充：
1. 工作组是数据归属与人员授权单位，项目直接继承工作组成员权限，一期不设项目级授权，原“项目-权限”不再保留。
2. 一个用户在一个工作组最多一条成员记录；没有有效成员即无组内访问权。申请与获批身份分开保存，批准、成员更新和审计同事务。
3. 系统管理员可任命组管理员；组管理员管理本组项目及工作/只读人员，不能任命同级管理员。待审申请可由本人撤回，已办结申请只读保留。
4. 精确坐标与数据下载按成员控制。组管理可查看坐标并下载；工作可查看坐标，下载需开关；只读两项均需开关。可下载不等于可获得无权坐标，导出须脱敏。
5. 生境按 location_habitat 的观察日期留历史；相机参数保存在维护后的配置及周期起始快照。周期内故障恢复已确认存在，一期使用 deployment_work_interval 多段记录；未完整核实不以首末跨度计算工作量。
6. 一期不建设相机库存；独立拍摄继续使用媒体/物种标记，固定类型选项用字段 CHECK，不恢复事件或逐字段字典表。
