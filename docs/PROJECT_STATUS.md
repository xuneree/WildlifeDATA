## 已确认、尚未同步完成的业务变化

### 位点动态状态（本次对话）

用户已明确确认：

- 布设类型和启用状态随时间变化，不是位点或布设周期的固定属性，不在位点表单手填。
- 同一时刻在位 0 台为停用、无布设；1 台为启用、单侧；2 台为启用、对拍。
- 启用只表示相机在位，故障相机仍计入在位；不能以有效工作时长或周期内累计关联数量代替在位数量。
- 应从相机操作记录还原指定时间的在位状态；换机不会因周期内累计关联两台而自动变成对拍。

当前差距：guide 仍列手填字段；需求 V1.4/数据库 V1.5 尚未按此修订；当前表单 demo 仍显示布设类型和位点状态输入，并默认单侧、启用。**这项原始修改请求尚未在正确的文档和表单 demo 中完成。**

建议用户补入 guide 的文字：

> 位点布设类型及启用状态按查询时刻的相机在位情况自动推导，不手工填写，不固定在某一布设周期。0 台无布设/停用，1 台单侧/启用，2 台对拍/启用。故障相机仍视为在位；在位状态与有效工作时间分开记录，以相机操作记录还原历史。

后续落实需沿用当前 location/camera/维护模型及表单的安装、检查、撤回流程，不能直接套用旧模型实验新增的操作枚举。现有设计和表单主要记录日期及同日顺序，对“某一时间点”的精度需要衔接；未知操作历史如何展示、超过两台如何处理也应明确，不能自行编造现场事实。
