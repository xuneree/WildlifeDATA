## 数据库实现决定

- 采用文档 20 张表的字段和外键；账号表增加 password_hash、role、regions、can_view_coordinates。
- 使用 UUID 稳定主键；位点唯一性采用 `(region, site_code)`，对拍编号存入周期表，不增加设备管理模块。
- 使用 TIMESTAMPTZ；API 拒绝无时区的时间点。有效拍摄时间应优先使用 time_corrected_at，媒体入库尚未实现。
- 物种导入快照和审计快照使用 JSONB；空间表达式使用 PostGIS GiST 索引。
- 代表图采用复合外键，确保 individual.profile_id 仅能关联自身代表图。
- 已确认个体出现采用 UNIQUE(media_id, individual_id)；unknown_individual 预置为标签，并禁止用作正式编号。
- 底表不做业务实体的级联删除，避免丢失被引用的历史证据。
- 初始迁移为已提交静态 SQL，不因运行时模型变化自动改写；后续模型修改须增加迁移。
- 历史编号与当前编号的全局冲突检查、改号事务、导入一致性均待专用服务实现，不开放通用写入接口。
- 普通账号暂不访问个体档案；后续需按授权区域的出现记录和经评审的共享策略决定身份可见性。

## 必须用真实数据验证的事项

1. XMP 命名空间、多物种和空标签结构；未匹配或未知代码不得覆盖旧标注。
2. Excel 的周期定位、媒体匹配键、多已知个体/未知标签、重复与更正策略。
3. 拷贝后文件 mtime 的稳定性、来源时区；首次记录不可静默重写。
4. 同批次重复回收、周期内停机复工；基础工作区间不能自动当作有效工作日。
5. 繁殖状态词表、代表图格式和跨区域身份共享规则。
