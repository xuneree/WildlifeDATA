# 模块1-相机管理

版本：V2.0 · 对齐日期：2026-11-16。状态：当前模块业务与交互基准，小修订由 Git 区分。[Word](module01-camera-management-v2_0.docx)由本文生成。

模块代码为 `module01`，对外统一称“模块1-相机管理”。包含位点信息、生境调查、操作记录、布设周期四类业务内容，不要求四者各占一级导航；当前入口以位点列表与详情组织。“操作记录”记录现场操作，不等同于系统审计日志。模块映射见[需求目录](README.md)。

## 依据与范围

依据用户确认的 V4.2 野外表单与后续审阅规则、[数据库 guide](../database/database_design_guide.md)、[使用场景](../design/scenario.md)，并对齐源码提交 `15b448a17898f7f5efd47ff05ebccdeb96c91039` 中的[当前 Demo](../demos/module01/README.md)。本版替代旧模块需求及低保真交互稿；[旧资料完整归档](../archive/module01-legacy/README.md)。已确认新规则优先于旧文档冲突描述，guide 由用户维护。

目标闭环：建立位点 → 按需调查生境 → 记录安装/检查/撤回 → 核对布设周期、故障与时间校准 → 为媒体归属和后续统计提供依据。当前 Demo 是独立浏览器原型，正式前端、后端及迁移仍待实现。

## 四类业务表单的当前规则

通用：桌面四栏、平板两栏、手机单栏；使用轻量分区。工作组从全局上下文带入，不在表单中填写。未填输入和未选下拉显示为空。不设历史补录模式，所有表单统一按字段及条件校验；可选项允许留空。

### 位点信息

| 分区 | 字段顺序与交互 |
| --- | --- |
| 布设信息 | 位点编号、区域、小地名、网格编号、关联项目；设置人员、选填记录人员、首次布设日期 |
| 在位状态 | 展示北京时间当天的在位相机数、布设类型、位点状态，只读且由已保存操作自动计算 |
| 别名 | 位点编号下方显示“别名：添加”；填写后为“别名：xxx 修改”，添加和修改是文字链 |
| 地理信息 | 经度、纬度、海拔、生境类型；地形位置、坡向、坡度、水源位置；不展示其他生境说明 |
| 现场资料 | KML 轨迹、位点照片、备注；两类文件各最多 10 个，可逐项删除，照片有缩略图 |
| 生境调查 | 当前位点的调查历史与新增入口；打开历史后可修改、删除 |

位点编号在工作组内唯一是业务约束，正式接入需由后端保证。网格编号为非必填文本，放在小地名后、关联项目前，允许字母及前导零；项目下拉多选且选填；布设类型和位点状态取消手填及默认值，由记录推导；水源位置为 ≤100 m／＞100 m。当前原型不实现跨工作组真实权限校验。

区域必填。经纬度采用 WGS84 十进制度，输入、保存、详情、Excel 及 KML/KMZ 坐标导出均保留六位小数，超出四舍五入、不足补零；轨迹原文件不转换。

### 位点在位状态

- 0 台无布设/停用，1 台单侧/启用，2 台对拍/启用；故障或关机仍算在位。超过两台保持启用，布设类型显示待核查。
- 按工作组、位点、机位分组，取查询日期及此前最后一条操作的 `is_deployed_after`。安装为在位；检查依据操作后的实际结果，故障、收卡换卡或换机不减少在位数量；撤回为不在位。丢失且未补装为不在位，丢失后补装为在位，未知丢失日期不向前推断。
- 当前界面只展示北京时间当天的已记录状态，同机同日按记录顺序处理。补录按操作日期排序；同机反复检查不重复计数，未来记录不影响当前，周期结束或数据回收不等于撤机。正式历史查询可按同一事实规则重算，不将计算能力写成原型已有日期查询控件。
- 操作历史不依赖最后一份表单草稿，位点基础信息不再保存手填状态。浏览器存储与导出细节见 Demo README。
- 没有位点编号时不显示结论；没有操作记录时按已录入事实计算为 0。旧版本的草稿、工作周期和静态设备示例不自动当作在位事实，已有位点须补录真实操作历史。历史资料缺失不等于现场已核实停用。

### 生境调查

- 基本信息：位点、调查日期、调查人员、选填记录人员。按需独立调查，不与相机操作强制绑定；观察人、记录人员和登录账号分别保留。
- 植被信息、动物痕迹、人为干扰各有一个“未调查”，放在分区标题右侧；未调查的内容不参与必填并导出为空。
- 植被按乔木、灌木、草本三行，四等分列宽且行末留空：乔木高度/郁闭度/森林起源，灌木高度/盖度，草本高度/盖度/类型。不增加树种胸径样本。
- 动物痕迹默认一条空记录，物种名称与痕迹多选为 1:3，可重复增加物种行；完全空白行不导出为发现记录，部分填写须补全。动物痕迹和人为干扰共用调查日期，不重复填写发现日期。
- 痕迹：实体、粪便、食迹、足迹、卧穴、爪痕、蹭痕、毛发、尸体。干扰：放牧、套子、电网、车辆、偷树、砍树、旅游、采药、其他。

### 操作记录

基本字段：位点、相机编号、操作批次、操作日期、操作类型、操作人员、选填记录人员。

**操作批次选填**：点击输入框展示当前工作组最近批次，可直接选入，也可自由输入；不做编号格式校验。

| 类型 | 表单表现 | 周期结果 |
| --- | --- | --- |
| 安装 | 型号和条形码空白填写，参数取默认值；不填操作前状态或操作内容 | 开启周期 |
| 检查 | 带入上一次相机信息，默认只读；下方填写相机状态、操作内容；备注放在操作内容中 | 结束上一周期，仍在位时开启下一周期；丢失未补装不开启 |
| 撤回 | 带入只读相机信息，填写现场状态及撤回原因；不填写操作内容 | 结束当前周期 |

相机信息保留必要的上次记录日期，型号必填、条形码选填。拍摄模式为照片、视频、照片+视频；连拍张数 1/2/3/5、视频时长以秒、拍摄间隔以秒、灵敏度高/中/低。当前新安装默认视频 15 秒、间隔 10 秒、灵敏度中，照片张数初值 1；旧分钟值按原值乘 60 迁移，不把既有实际间隔改成新默认。配置在操作后及周期起点留快照，不覆盖旧周期。

参数区固定展示“侧边PIR是否打开（A323型号相机）”及是/否；A323 可编辑，其他型号不要求填。现场状态为正常、关机、损坏、丢失、倒了、其他。设置/拍摄情况为无问题、空拍多、电池没电、相机设置有误、触发异常、其他；无问题与异常互斥，设置有误/触发异常/其他按条件填说明。列表摘要不显示“无问题”，异常仍展示。

检查动作为收卡换卡、更换电池、调整角度、更换相机、丢失重补、移动位置、参数调整、其他。更换/补装开放设备信息，参数调整开放拍摄配置，取消动作后恢复此前值；撤回填原因，不填检查动作。V4.2 附件已删除的诱饵、胸径、树种、时分及操作表中的“豹和人为干扰”不恢复。真实地理迁移仍应新建位点/机位，不将历史媒体移到新地点。

### 布设周期

- 周期由操作自动生成，不独立新增或手改边界；开放周期可查，已结束周期可补充故障及校准。检查/周期闭合不等于成功取得文件，空卡、损坏和未取回须在媒体来源核对时区分。
- 字段：位点、相机编号、布设开始日期、回收日期。不填型号、判断依据、确认人或完整核实确认框。
- 默认选择“无故障时间”；选择“有故障时间”后展开一条填写行，可添加多段。故障开始日期、恢复日期、故障说明为 1:1:2。
- 故障段须位于周期内且互不重叠；日期区间沿用原型的 `[开始日, 结束日)` 约定。
- 时间校准始终可填，无故障也可只校准：输入首条视频的相机时间和实际时间，自动计算本周期加减秒数。时间按北京时间 UTC+8 解释。
- 保存现场正常的相机操作后，内部保留周期关联与记录逻辑，界面不展示自动确认提示；已有故障事实不会因后续现场正常被清空。
- 正式日志使用登录账号；当前浏览器保存及示例账号不代表真实鉴权。周期默认无故障不等于已核实有效工作量，故障与有效工作区间的衔接仍待正式设计。

## 删除、导入与导出

操作列表和手机卡片不显示删除；进入只读详情后才可发起，二次确认对象和影响。删除保留原操作与周期快照，与周期重算、成功审计一起提交；失败保留原记录并支持重试，旧编辑页不能恢复已删操作。起点已删除的空周期可移除；已有故障/校准信息的周期保留为待核对。

位点从详情“更多位点操作”删除，操作、周期、调查、附件及审计全部保留，编号不复用，不代表现场撤机；删除位点不能接收新增或导入操作。这是可追溯业务移除，不授权硬删除被引用事实。正式权限、删除标记结构及已有媒体引用下的更正/重挂仍待设计；引用未解决时阻断更正，不自动改挂或级联删除媒体。

Excel 已在当前 Demo 支持位点和操作：模板下载、真实 XLSX 读取、条件字段预检、重复与引用校验、整批提交及提交前复验，每批最多 1000 条/10 MB，任一错误整批不写。同键同内容幂等跳过，同键不同报冲突；不同批次不能覆盖已有记录。编号保留前导零、日期为 YYYY-MM-DD、多选用顿号，操作导入同步周期及审计。演示数据同相机同批次仅一条不构成正式业务唯一约束。

列表勾选可导出坐标、轨迹、照片，多项按位点打包 ZIP；坐标可选 KML/KMZ，轨迹/照片保持原文件。浏览器支持时允许选择保存位置，正式下载须按总体权限复验。


## 正式实现边界

- 数据归属工作组，项目继承工作组权限；位点可关联本组多个项目，项目选填。机位、调查、操作、周期应采用稳定 ID 关联，不依赖名称或日期文本匹配。
- 工作与管理身份可维护本组业务；只读不能写入。精确坐标、轨迹、下载和审计按总体需求权限控制，后端每次验证，原型示例账号不代表真实权限。
- 修改业务及成功审计同事务；保存失败保留输入，不写部分记录。业务引用保护、并发校验及日志账号由正式接口实现。
- Excel 原型已实现位点/操作，生境与周期批量模板仍待设计；正式预检、提交需重验权限、唯一性和并发并保障整批事务，不以浏览器实现冒充后端完成。
- 无记录的在位数量 0 只是已记录事实，不能作为现场已核实停用的证据。资料不足时不输出正式有效工作量；故障多段区间与“未完整核实不按首末跨度统计”原则的正式核实流程仍待衔接。界面不重新增加已取消的人工确认字段。
- 媒体入库、播放、物种/个体标注和生态统计由对应模块实现；本模块不新增实体相机库存或项目级授权。
