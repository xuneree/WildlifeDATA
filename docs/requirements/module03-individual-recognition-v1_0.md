# 个体识别模块需求

V1.0 · 2026-11-16 · 当前业务与交互基准

模块标识沿用 `module03`，对应 Demo 的 `#/individual`；总体需求原九模块表中的个体识别序号为 5。模块映射见[需求目录](README.md)。依据用户确认的新版 `个体识别数据样例.xlsx`、[总体需求](platform-requirements-v1_4.md)及截至源码提交 `15b448a17898f7f5efd47ff05ebccdeb96c91039` 的[独立 Demo](../demos/module03/README.md)与[整合 Demo](../demos/integrated/README.md)整理。本文只维护 Markdown。

## 1. 范围与页面定位

个体识别是独立导航入口，默认展示个体识别记录，支持筛选、详情、Excel 导入和下载。导入是页内弹窗功能，不另设标签导入入口或重型独立流程。一期导入平台外已完成的结果；二期人工个体标注、比对与复核工具沿用同一有效记录层，不另造身份体系。

个体识别记录表达一次媒体中的出现与识别观察，个体档案表达长期身份信息；两者保持独立模块。一个媒体允许多个已确认个体，也允许已确认个体和未知个体同时存在。未完成物种或个体标签导入不阻止原媒体的授权查询与播放；物种识别和个体识别不做强制串行页面向导。

## 2. 页面与流转

| 入口 | 默认内容与操作 | 操作后返回 |
| --- | --- | --- |
| 个体识别导航 | 标题与导入/下载 → 九项筛选 → 识别记录表格 | 页内更新记录 |
| 记录查看 | 只读详情抽屉；可复制原始路径、下载单条 | 关闭回原列表，保留筛选与分页 |
| 导入 Excel | 同一弹窗内选择文件、预检、确认提交及实际结果 | 关闭后更新列表，保留筛选 |
| 导入记录 | 工具栏入口打开历史弹窗 | 关闭回列表 |
| 下载数据 | 弹窗选全部、当前筛选或跨页已选 | 下载后回列表 |
| 正式关联入口 | 从记录进入媒体或已有个体档案；从档案拍摄历史进入相关记录/媒体 | 返回时恢复来源上下文 |

最后一行是正式平台的关联目标，当前 Demo 尚未接入档案、NAS 和跨模块稳定 ID。缺失已确认个体档案时须明确建档或补建，再返回重验；不得按模糊编号静默新建。未知个体无需建档。

### 2.1 筛选与列表

筛选仅保留区域、小地名、项目、位点、回收批次、拍摄时间、关键词、个体编号、复核状态九项。区域/小地名/项目经位点关系获得，不从路径推断；多项目关联不复制记录。关键词范围沿用当前记录实现，正式接口查询字段需在接口设计中明确。

不增加年龄、性别、相机编号、识别人、复核人、可识别性、角度、确信度筛选；不设“更多筛选”、个体编号数量标签或“仅个体独立拍摄”勾选。这些源观察仍在详情和下载中保留。

桌面第一行六项位置/批次/时间条件；第二行关键词占两列，个体编号和复核状态各一列，右侧留空。平板三列、手机两列。条件即时组合筛选并回第一页，重置清除所有条件。表格保留拍摄时间排序、分页、跨页勾选和原有操作列；工具栏仅保留导入记录入口，不照搬物种标签点选区。

### 2.2 详情

按位点信息、个体出现与复核、媒体信息、识别观察、时间校正与来源五组展示。区域、小地名、项目、位点和相机编号集中在位点信息组，媒体组不重复；字段名与内容列宽统一为 32% : 68%，长文本换行。编码展示中文释义并可查看源值；来源路径只在有权范围展示，不公开 NAS 凭据。

## 3. 源数据与身份规则

| 内容 | 业务含义与保留规则 |
| --- | --- |
| 路径、文件、位点、相机、批次 | 媒体匹配上下文；批次不代替周期 ID，文件名不足以唯一匹配媒体 |
| 个体编号复核 | 已复核后的编号候选，正式关联稳定个体 ID；同媒体同个体只保留一条当前有效出现记录 |
| 未知个体 | 空编号或 `unknown_individual` 按未知标签处理，不建虚拟档案，不据此计算未知数量或跨视频身份；包含 unknown 字样的完整源编号不自动改写为未知标签 |
| 识别人、复核人及状态 | 分别保留；缺失复核人时当前已确认的这套 Excel 模板默认 CS，不覆盖识别人，不推广为其他来源的统一默认值 |
| 表头与复核状态 | “个体编号复核”列且未显式给状态时按已复核读取；普通“个体编号”缺状态为未复核，显式状态优先；标注/复核时刻缺失不拿导入时间补造 |
| 数量 | 整段视频中的豹个体数量，同媒体多行须一致，不逐行求和，不据此计算独立个体数 |
| 成年、性别、角度、伤情、行为、确信度 | 本次识别观察；不自动覆盖长期档案性别、出生年份、代表图或存活状态，不将确信度字母换算为百分比 |
| 多豹行为、繁殖情况及备注 | 保留本次观察，不自动创建个体关系或二期繁殖事件；未知关系、未再出现均不推断死亡 |
| 个体独立拍摄 | 来源的个体连续拍摄标记，保留 1/0/空值；不写成文件级或物种级独立标记，不据此计算 RAI |
| 原始与校正日期 | 保留两者，列表及日期筛选优先校正日期、无值回退原日期；只有日期校正时不伪造校正时刻、时区或周期偏移 |
| 上一次拍摄时间 | 保留源辅助值，包括 00:00:00；无日期及稳定关联时不构造上一媒体外键 |

可识别性、复核状态、导入完成状态分别表达不同事实。`annotated` 不意味着所有个体身份均已确认；未知身份仍可作为已标注结果保存。原始与复核备注均保留，不合并写入档案说明。

## 4. Excel 与轻量导入

支持 `.xls` / `.xlsx`，单文件不超过 20 MB；读取首表，忽略全空行，兼容新版样例说明性长表头及简洁标准表头。编号、日期精度、编码、空值与时间原值保留，提供同结构模板。

当前模板含 26 个源字段：文件夹、文件名、相机编号、位点、拍摄日期、拍摄时间、视频中豹个体数量、位置描述、可识别性、角度、是否成年、性别、个体编号、复核备注、受伤情况、多只豹情况下的行为、繁殖情况、行为、识别人、确信度、备注、回收批次、个体独立拍摄、拍摄日期可能有误、校正后拍摄日期、上一次拍摄时间。加复核人、复核状态共 28 列，下载另有字段说明工作表；源编码和空值可往返保留。

流程为：选择/拖拽文件 → 自动预检 → 在同一弹窗查看待新增、重复、问题及预览 → 确认提交 → 实际结果。错误按 Excel 行号、字段和原值展示；任一问题阻止整批写入。失败保留旧记录，不能显示导入成功；成功后返回当前列表上下文，导入历史通过页内弹窗查看。

当前 Demo 完整相同行跳过；有编号时按媒体上下文＋个体编号识别冲突，内容或复核信息改变时阻止直接覆盖。这是原型的防误写机制，不代表正式更正能力已完成。正式更正仍须逐媒体匹配完整集合、展示前后差异并由操作者明确确认替换；业务、完成状态、前后快照、导入项及成功审计同事务。失败、匹配歧义或档案缺失均不能清除原结果；批次外媒体不受影响。

## 5. 权限与接入边界

沿用工作组成员权限：只读可查，工作及管理可导入，下载另检开关。项目继承工作组权限；本组记录不能暴露其他工作组的档案、代表图、拍摄汇总或位点。预检、提交、历史及下载均验证当前权限和版本，不复用已撤销的旧授权。

正式媒体与个体须通过稳定 ID 同组关联；源观察快照与永久档案字段分开设计。物种与个体出现记录冲突时须核对，不静默删关联或补造物种标签。现有数据库设计尚未完整承载全部源观察、日期级校正及个体独立标记，正式接口设计时明确映射，不将 Demo 投影视为可直接执行的数据库载荷。

## 6. 验收与当前完成范围

| 场景 | 预期 |
| --- | --- |
| 进入、查看详情及返回 | 识别记录为主体，九项筛选不增加；详情分组与列宽统一，返回保留上下文 |
| 多项目、多个体、未知编号 | 不因项目复制记录；同媒体允许多个身份；未知不建虚拟档案 |
| 新旧表头、复核信息及日期 | 来源明确、显式状态优先、识别人不覆盖；校正日期优先但不造时刻 |
| 同媒体数量与重复变更 | 数量不一致报错；完全重复幂等；变化不静默覆盖 |
| 导入失败及下载 | 错误整批不写；28 列保留编码、空值、时间和观察信息 |
| 正式档案关联、更正、并发与权限 | 稳定匹配、明确建档、逐媒体差异确认、事务及审计，待后端接入验证 |

Demo 已完成样例导入、九项筛选、记录、详情、导入/历史弹窗和下载，数据仅在当前浏览器；正式媒体、档案及权限未接入。样例来源、运行和既有测试结果见 [Demo README](../demos/module03/README.md)。

待正式设计：源观察快照、未判定个体独立标记、日期级校正与完整时刻/时区的关系、媒体/档案稳定匹配及更正接口。不将这些接入事项写成已完成能力。

建议用户补入 guide：个体识别以记录列表为独立导航，Excel 导入及历史在弹窗完成；按新版表格保留源观察和复核信息，筛选仅九项，不增加年龄/性别或个体标签点选。来源观察不自动更新长期档案，个体独立拍摄不等于物种或文件独立标记；具体模板和默认复核规则见本文，不扩大到其他来源。
