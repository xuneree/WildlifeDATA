## 1. 范围与页面定位

物种识别是独立导航入口，默认显示已有识别记录，提供查询、筛选、详情查看、Excel 导入和下载。导入是页内操作，不另设“标签导入”导航、独立导入页面或全局导入中心。当前一期先支持 Excel；XMP 是否接入及其范围另行确认，不列为当前必验能力。AI 识别和平台内人工识别/复核工具不纳入本轮。

一个媒体可有多个物种标签；不由标签推断动物数量、检测框或帧时段。空拍、人类干扰等非动物标签须与生物物种区分。识别记录数、唯一媒体数、生物物种数不能混用；本页面不计算 RAI。

## 2. 页面与流转

| 入口 | 默认内容与操作 | 操作后返回 |
| --- | --- | --- |
| 物种识别导航 | 标题及导入/下载按钮 → 筛选条件 → 识别记录数量、标签筛选项及表格 | 页面内更新列表 |
| 记录查看 | 只读详情抽屉，展示完整路径、源标签及位点关联信息；支持单条下载 | 关闭后回到原列表，保留筛选和分页 |
| 导入 Excel | 单个弹窗内选择文件、数据预检、确认提交及实际结果 | 关闭后更新列表，不清空用户筛选 |
| 导入记录 | 列表工具栏打开历史弹窗 | 关闭后回原列表 |
| 下载数据 | 弹窗选择全部、当前筛选或跨页已选记录 | 下载后回原列表；单条下载从详情发起 |
| 标签映射 | 维护抽屉显示原始标签及影响记录数，保存映射 | 刷新筛选及数量，不改写源标签 |

正式关联接入后，详情可追溯到授权范围内的媒体、位点和布设周期；当前 Demo 的演示目录不等于已接通跨模块服务。跨模块切换保留各模块已访问页面的筛选和分页，不要求先完成个体识别才能浏览物种记录。

### 2.1 筛选与记录

- 筛选项为区域、小地名、项目、位点、相机编号、关键词、物种标签、回收批次、拍摄时间。区域/小地名/项目通过位点关系获得，不从文件夹名称猜测。项目多选关联不复制识别记录，未关联项目的位点仍可在无项目限制时查询。
- 条件以“且”组合，即时生效并回第一页；支持重置、无记录与筛选无结果状态。关键词覆盖文件名、原始路径、归并标签、原始标签、位点及相机。
- 桌面五列：第一行五项位置/相机条件；第二行关键词占两列，其余物种标签、批次、时间各一列。平板三列、手机两列。
- 表格支持拍摄时间排序、分页、跨页勾选。记录工具栏提供导入记录及“仅独立拍摄”；该勾选在修改其他筛选时保留，重置时清除。
- 识别记录标题只展示当前记录数；下方直接展示标签筛选项，每项只有标签名与数量，不另设统计卡片、标签标题、标签总数或位点数。
- 标签数量按上方条件形成的基础范围汇总，忽略分页和勾选；按数量降序、同量按中文名称排序。点击标签进一步筛选，切换、再次点击或清除可改变选择；标签分布保留基础范围，列表数量与筛选下载随选择更新。修改上方筛选时清除标签进一步选择。

### 2.2 标签与独立拍摄

工作人员、其他人、采药人、伐木人默认归并为筛选类别“人类干扰”；列表、详情和下载保留具体源标签。映射可增删原始标签、预览影响量并保存；移除映射可恢复具体类别，不重写历史源值。正式服务须共用受权限控制、可追溯版本的配置；谁可维护映射及非动物标签的正式承载方式在接入设计时明确，不将映射权限默认授予所有成员。

本 Excel 来源独立拍摄 `1` 为是，`0` 或空值为否；导出仍分别保留 `0` 和空值。正式映射时本来源空值对应 FALSE，并保留原输入；这不改变其他来源 NULL 表示未判定的规则，不将源标记直接作为任意筛选范围下的正式独立拍摄次数或 RAI。

## 3. Excel 与轻量导入

| 项目 | 当前规则 |
| --- | --- |
| 文件 | `.xls` / `.xlsx`，单文件不超过 20 MB，读取首个工作表，提供模板下载 |
| 标准九列 | 文件夹、文件名、位点、相机编号、拍摄日期、拍摄时间、物种标签、回收批次、独立拍摄 |
| 兼容表头 | 位点名称 → 位点，物种 → 物种标签，回收时段 → 回收批次；同字段新旧表头不能同时出现，列顺序可调整 |
| 编号与时间 | 编号按文本保留前导零；日期支持 Excel 1900/1904 序列及日期文本，时间支持 Excel 小数及时间文本；保留原始来源，不擅自确定时区 |
| 预检 | 汇总待新增、重复和问题；按行号、字段及原值展示错误，可重新选择文件；有错误时整批不写入 |
| 提交与结果 | 预检通过后在同一弹窗确认；保存失败保留原记录并反馈失败，只有实际保存成功才显示成功 |
| 下载 | 真实 `.xlsx`，按九列标准表头和顺序输出，保留原始标签、路径及独立拍摄原值 |

预检、差异确认和错误反馈在弹窗内完成，不扩展为跨页向导。常规导入与历史更正需明确区分：完全重复应幂等；变更已有媒体结果时，展示完整媒体匹配与前后集合差异，获得明确替换意图后才提交；失败、歧义及未知标签不能覆盖旧结果，空标签不默认清空。

当前 Demo 以“完整路径＋文件名＋归并标签”暂定去重，完全相同跳过、同键不同内容报错；其他八字段必填、已知标签集合来自样例与映射。这些是原型实现边界，不是已确认的正式唯一键、必填性或物种字典契约。正式接入应结合授权工作组、稳定媒体 ID、周期及目录上下文核验，不仅按文件名匹配，不直接照搬 Demo 键。

## 4. 权限、追溯与模块边界

读取按有效工作组成员控制；工作及管理身份可导入，下载另验下载能力，坐标按附加权限过滤。项目筛选不产生授权。导入预检、提交及历史读取均校验当前权限；业务更新、前后快照、来源及成功审计同事务，失败不修改当前有效记录。

人员与复核信息如源文件提供须追溯保留，缺失不伪造；九列表格未提供标注/复核账号时如何映射另行设计，导入人不自动等同标注人。正式系统只输出成员有权查看的路径和关联信息，不因原型可复制路径就公开 NAS 根路径或访问凭据。
