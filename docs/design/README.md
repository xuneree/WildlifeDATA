# 交互与界面设计

本目录用于页面流程、交互说明、线框稿、视觉设计稿、设计规范及对应的评审意见和图件；后续设计稿可按模块建立子目录。数据库设计单独放在 [../database](../database)。

界面技术基准：[Ant Design 使用基准](ant-design.md)。项目采用 Ant Design；本文件规定组件选型与实现方式，不替代业务需求。

当前页面流转：[平台导航及页面关系](../requirements/platform-requirements-v1_4.md#21-按导航推进的模块与页面)；模块标识及文档维护分工见[需求目录](../requirements/README.md)。

本目录只保留当前 Ant Design 基准、列表规范、相机交互说明和使用场景。历史草案及旧模块 guide 见[统一归档](../archive/README.md)，不再在原路径保留入口文件。
