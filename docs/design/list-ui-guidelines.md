# 列表视觉与交互规范

适用相机位点、操作记录、布设周期、生境调查及物种识别列表。沿用 [Ant Design 使用基准](ant-design.md)，保持各模块字段与业务规则。当前落实于 module01；module02 作为卡片层次及数字内容的参照，其源码未在本次修改。

## 文字与密度

| 内容 | 字号 / 字重 | 用法 |
| --- | --- | --- |
| 中文及中英混排正文 | 13px / 400 | 地名、项目、人员、操作内容；混排不逐字切换字号 |
| 纯英文编号、日期、文件名 | 14px / 400 | 补偿拉丁字符视觉尺寸；日期和编号使用等宽数字，保留正常字体，不使用代码字体 |
| 次要信息 | 12px / 400 | 批次、别名、辅助说明；纯数字出现在次要信息内也用 12px |
| 表头 | 13px / 600 | 不因文本语言改变列标题大小 |
| 分区标题 | 14px / 600 | 数量以次要颜色展示 |
| 状态和动作标签 | 12px / 400 | 使用语义颜色，避免用大字号强调；文字标签始终可读 |

正文行距 20px，次要说明行距 18px，单元格上下留白 8px、左右 12px。双行高度随内容自然增长，不固定高度裁切中文。相机状态与实际操作置于独立列，异常信息使用警示色；日期不整列加粗。手机沿用同一文字分级，以布局重排解决空间问题。

保留标题和高频主要操作、筛选区、记录区的层次。位点列表用独立筛选/记录卡片；详情内操作记录/布设周期用同一记录容器下的标签页，右侧优先展示布设和地理信息，现场资料缩略为轨迹/照片数量，生境调查缩略为最近日期；左下角“查看全部”打开独立完整信息页，依次分布设信息、地理信息、现场资料、生境调查，最新调查结果直接展示，并支持历史和新增调查；窄屏移到主区域下方。筛选控件 32px，次要按钮 24px，组件视觉通过共享 Token 配置。表格横向空间不足时提供可见横向滚动或卡片，不挤压或隐藏业务字段。

## 查看与编辑

- 点击整行或整张卡片查看；行可通过 Tab 聚焦，Enter/空格执行同一动作，具备可见焦点。位点进入详情页；操作、周期、调查打开只读抽屉。
- 勾选、链接、行内按钮独立响应，不冒泡触发行跳转。不保留重复的“查看/详情”操作列。行内保留高频业务动作，如新增记录。
- 默认展示已保存信息。新增/修改通过明确入口进入表单，保留已确认条件字段逻辑；周期只能补充故障与校准，不手动新增或修改边界。
- 关闭只读抽屉返回原列表，不清空筛选和分页。调查详情提供返回调查列表入口，避免叠加抽屉。修改保存后的定位遵循已有表单流程。

## 筛选、分页和选择

- 筛选即时生效并回到第一页；全部条件以“且”组合。重置清空当前列表筛选并回第一页，无条件时禁用重置。
- 每页 10 条，显示总数与当前范围。返回位点列表保留筛选和当前页；删除导致当前页失效时回到最后有效页。
- 仅需批量操作的列表提供勾选。选中数量明确展示，可取消选择；批量操作只对已选记录执行，筛选不悄悄改变选择范围。
- 分开表达暂无记录和筛选无结果，后者可重置条件。读取/保存失败应保留数据及重试入口，不显示成功反馈。
- 删除明确对象和后果并二次确认；失败保留原记录。导入保留预校验、错误行和确认步骤。
