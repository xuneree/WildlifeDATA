# 平台交互规则草案

版本：0.1 · 2026-10-15；状态：设计建议，随模块 01 原型验证后修订，不代表已确认的全平台规范。

## 1. 用词与信息

- 统一“一级区域、二级区域、位点、相机编号、回收批次”，不将二级区域称为保护区。
- 位点停用与周期未回收使用不同状态；数据已回收不表示影像可用或媒体已导入。
- 现场日期显示 YYYY-MM-DD。未知、无权限和数值 0 分开表达，不用同一个占位符混淆。

## 2. 列表与表单

- 进入详情再返回时保留原筛选、分页和必要的滚动位置。
- 必填标记、字段说明及错误靠近输入项；不在点击保存失败后清空已填内容。
- 固定选项用选择控件；编号按文本处理，保留前导零；字段限长、权限与后端规则保持一致。
- 多行表格以行/单元格错误定位为主，汇总提示辅助；可用键盘操作，焦点清晰。

## 3. 操作与反馈

- 主要动作与次要动作有明确层级；忙碌时防重复提交并显示处理状态。
- 删除、停用、丢弃未提交内容及覆盖批量值分别说明具体影响，不用同一通用确认文案。
- 加载、无记录、筛选无结果、无权限和请求失败分别显示；错误不靠颜色单独表达。
- 批量提交前显示范围和数量，结果显示实际写入情况；未提交的草稿不能显示为已保存。

## 4. 权限与视觉设计

- 不可操作时根据实际场景隐藏入口或解释限制；后端始终独立验证权限。
- 符合权限的数据才进入页面，不仅将精确坐标用 CSS 遮住。
- 本阶段先验证导航、密度与操作流程；字体、颜色、间距、控件尺寸和响应式规则随首版原型确定，再抽取共享组件。
