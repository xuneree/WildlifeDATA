# 模块1-相机管理交互说明

对齐日期：2026-11-16；业务正文见[需求 V2.0](../requirements/module01-camera-management-v2_0.md)，实现及既有验证见[Demo](../demos/module01/README.md)。

位点信息、生境调查、操作记录、布设周期是四类业务内容，不要求四个并列一级页面。当前从相机管理进入位点列表，再进入位点详情：主区为操作记录/布设周期标签页，相机下拉统一筛选；侧栏为布设、地理、附件数量和最近调查摘要。“查看全部”进入完整信息页，依次展示布设、地理、现场资料、最新调查，并提供调查历史及新增入口。

列表每页 10 条，返回保留筛选和分页。新建先填位点再登记首次安装，提交回列表且新增位点置首。操作/周期/调查默认只读抽屉，关闭返回来源记录，不堆叠抽屉。新增/修改操作以明确标题和左上返回组织，保存或取消回来源详情；删除仅在详情发起并确认影响。周期自动形成，不新增或改边界，仅已结束周期补故障及校准。

表单使用桌面四栏／平板两栏／手机单栏。工作组来自全局上下文；错误靠近字段，保存失败保留输入。当前位点状态只读展示北京时间当天；历史事实可重算，不将其写成 Demo 已有日期查询控件。调查按需独立记录，不强制每次操作调查。窄屏摘要移到主区下方。

字段、删除及周期规则只维护在需求正文。位点和操作 Excel 已有模板、预检、确认与结果交互；生境/周期批量模板及正式后端接入仍待设计。本次对齐不修改 UI 源码或部署。

遵循[Ant Design 使用基准](ant-design.md)。界面只展示业务字段、必要校验和操作反馈，开发说明与评审信息留在文档中。旧[交互草案](../archive/design/module01-interaction-v0_1.md)仅供追溯。
