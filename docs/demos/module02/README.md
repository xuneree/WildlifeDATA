# module02 · 物种识别 Demo

本目录是独立交互原型。依据本次用户确认的“Excel 导入、列表查看、筛选和下载”范围、[Ant Design 使用基准](../../design/ant-design.md)及附件 `物种识别数据样例.xlsx` 制作。业务对象参考[总体需求 V1.4](../../requirements/platform-requirements-v1_4.md)、[数据库设计 guide](../../database/database_design_guide.md)和[数据库设计 V1.5](../../database/wildlife_database_design_v1_5.md)。没有新建需求版本；本次源码基于主仓库 `1f9838a`，后续修改由 Git 提交区分。

[在线预览](https://wildlife-module02-demo.golden-reed-8427.chatgpt.site) · [源码 ZIP](module02-demo.zip)

本原型不改正式 `frontend`，不代表生产数据库、工作组权限、物种字典服务或媒体播放已接入。解析与保存发生在当前浏览器，沿用上次原型的本地存储键，旧记录可继续查看。文件不上传服务器；清除浏览器数据会清除导入记录。存储写入失败时不显示导入成功。

## 页面与交互

- 主页面：导航 → 标题及导入/下载 → 筛选 → 数据统计 → 列表，主要动作只有“导入 Excel”。
- 筛选按五组排列：区域/小地名/项目，位点/相机编号，关键词/物种标签，回收批次/拍摄时间，以及“仅独立拍摄”勾选框。桌面端前两组在第一行，后三组在第二行；保留位置分组但不显示区域与项目等组内小标题，减少重复文本与间距；窄屏逐组排列。关键词可搜索文件名、原始路径、归并标签、原始标签、位点和相机。勾选时只看独立拍摄，未勾选时显示全部记录；组合条件即时生效，支持重置与无结果状态。
- 列表：分页、拍摄日期时间排序、跨页勾选、文件夹列展开；详情抽屉展示 9 个字段及通过位点关联的区域、小地名、项目；“拍摄时间”列合并显示日期与时间，独立拍摄“是/否”用次要文字，不显示状态图标。返回保留筛选与分页。
- 导入：选择/拖拽文件 → 首个工作表预检 → 确认 → 实际结果。支持 .xls/.xlsx、20 MB 上限、模板下载。首行为全部 9 个中文表头，可调换顺序。当前模板与下载使用“位点”“物种标签”“回收批次”，兼容附件旧表头“位点名称”“物种”“回收时段”；同字段的新旧表头不能同时出现。编号按文本保留前导零；日期兼容 Excel 1900/1904 序列和 YYYY-MM-DD，时间兼容 Excel 小数和 HH:mm[:ss]。问题按 Excel 行号、字段和原值显示；有任一问题则整批不新增。
- 下载：全部、当前筛选结果、跨页已选记录或单条记录。输出真实 .xlsx，按附件顺序保留 9 个字段，采用标准表头与归并后的“人类干扰”标签，日期为 YYYY-MM-DD 文本，独立拍摄 0 与空值不混淆。

附件原始为 200 条记录、17 个标签、4 个位点；独立拍摄 133 条为 1、67 条为空。按用户确认，将工作人员、其他人、采药人、伐木人归并为“人类干扰”，共 19 条；归并后显示 14 个物种标签，包含空拍等非动物标签，不能称为 14 个生物物种。原始附件不改写；记录保留 sourceSpecies，在详情中可查看“原始标签”。已有浏览器记录读取时使用相同归并规则，不清空缓存；导入去重也使用归并标签，重导原附件仍按原记录识别。独立拍摄 1 表示是，0 或空值均表示非独立拍摄；0 或空值在列表及详情显示“否”，未勾选“仅独立拍摄”时也包含这些记录，导出仍保留独立拍摄原值。统计以当前筛选与标签进一步筛选后的记录为范围（不受分页或勾选影响），筛选与列表之间仅保留紧凑的标签统计条，标题为“物种标签（N）”，每个可点击标签只显示名称和数字，不重复显示“条”；识别记录数与位点数合并至列表标题（如“识别记录 200 条 · 位点 4 个”），不再单独显示独立拍摄数；仅汇总导入标记，不计算 RAI 或独立事件次数；文件夹字段保留附件中的原始完整路径。

## 数据统计与标签进一步筛选

统计区移除独立拍摄数、独立的物种标签总数、大数字、分隔线和常驻说明，保留“物种标签（N）”及标签数量按钮。N 是当前基础筛选范围内展示的标签种类数，不写死为某个示例数字；每个标签显示名称与裸数字，按识别记录数降序、同量按中文名称排序。统计口径和点击提示放在标题悬浮说明中。无结果时显示“物种标签（0）”和“暂无数据”，不使用插图撑高。

识别记录数和位点数只在识别列表标题处显示，随当前筛选及标签进一步筛选变化，忽略分页和跨页勾选。窄屏将导入记录和文件夹切换操作改为有可访问名称的图标按钮，确保列表标题中的两项数量完整展示。

标签按钮基于上方筛选条件（包括其物种标签选项）形成的基础范围。点击标签进一步筛选，按钮显示选中状态；点击其他标签切换，再次点击同一标签或“清除”返回基础范围。列表标题数量、记录和当前筛选下载同步缩小；标签分布及标题 N 保持基础范围，方便比较与切换。修改任一上方筛选条件时清除统计标签选择，重置清除全部条件和标签选择。

工作人员、其他人、采药人和伐木人在初始样例、已有缓存、新导入、筛选、标签统计、列表和下载中统一为“人类干扰”。仅归并附件已知的人类标签，不按含糊文本推断新类别；原始分类保留在 sourceSpecies，不作为新的统计标签。

## 源码入口

`src/workspace.tsx` 为组件与交互；`src/theme.ts` 为唯一主题入口；`src/data.ts` 为字段、校验和存储；`src/excel.ts` 为延迟加载的 Excel 读取及下载；`src/sample.json` 为附件逐行转换的初始数据。`src/statistics.ts` 维护筛选、数量汇总和标签进一步筛选。`tests/data.test.mjs`、`tests/locations.test.mjs`、`tests/statistics.test.mjs` 共包含 16 项数据行为回归测试。截图在 `screenshots/`。

## 待同步与待确认

已确认：本次一期 Demo 采用 Excel，区域/小地名/项目通过位点关联并先使用独立的演示目录，导入表格中的独立拍摄空值表示非独立拍摄。正式接入时，此 Excel 来源的空值应映射为非独立拍摄（FALSE），保留原始输入用于追溯；不据此改变其他来源中 NULL 的含义。总体需求 V1.4 的物种导入仍写 XMP，本次不回退用户最新要求，也不直接修改用户维护的 guide。建议用户同步的文字：

> module02 物种识别一期先支持 Excel 导入已有识别结果，按样例提供列表查看、组合筛选和 Excel 下载；XMP 接入范围另行确认。Excel 中独立拍摄为 1 表示独立拍摄，0 或空值均表示非独立拍摄；筛选按业务关系分组，独立拍摄使用“仅独立拍摄”勾选项。筛选与列表之间用紧凑标签条展示“物种标签（N）”和每个标签的裸数字数量，不再展示独立拍摄数；识别记录数和位点数合并到列表标题；点击标签进一步筛选列表，可切换或清除。人类相关标签统一归并为“人类干扰”。界面统一使用“物种标签”“位点”“拍摄时间”“回收批次”；模板采用新表头，导入兼容旧表头“回收时段”。区域、小地名和项目通过位点关联，其中一个位点可关联多个项目。

原型暂定规则：以“完整路径 + 文件名 + 物种标签”识别同一条记录，完全一致跳过；同键内容不同则阻止导入并保留原记录，不自动覆盖。可用标签以附件已有集合代替正式字典，未知标签报错，不自动建字典。其他 8 字段必填，独立拍摄允许 1/0/空值。其中独立拍摄空值表示非独立拍摄已经用户确认；其余是可评审的原型规则，尚未成为已确认的正式入库契约；正式接入前确认唯一键、必填性、物种/人员/空拍分类及更正追溯策略。

工作组和下载权限需由正式服务端实现；当前原型只用于查看附件与交互评审，不据此宣称已有真实权限隔离或并发事务保证。
