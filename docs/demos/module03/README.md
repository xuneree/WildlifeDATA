## 当前样例

新版 Excel 有 26 个源字段、36 条有效记录，尾部 226 行为空白，不作为业务记录。包含 36 个完整媒体路径、9 个编号、8 个位点、13 个相机编号；回收批次为 202606。24 条个体独立拍摄标记为 1，另外 12 条为空。`tests/fixtures/个体识别数据样例.xlsx` 为本次附件原件，`src/sample.json` 为有效行逐字段转换，日期和时间按原精度保留。

按用户要求补齐全部样例的复核人 **CS**。编号原列为“个体编号复核”，因此样例作为已复核结果展示；识别人保留 MY/QF、MY、CS 等原文，不用 CS 覆盖标注人。未提供标注时间及复核时间，不使用导入时间代替。

## 字段理解与数据库对应

| 表中内容 | 对应对象与处理 |
| --- | --- |
| 文件夹、文件名 | 媒体的 storage_path、filename。附件“文件夹”实际是包含文件名的相对存储路径，原样保留；不凭相同文件名匹配媒体，也不补造 NAS 根目录。 |
| 相机编号、位点、数据期号 | 导入媒体匹配上下文。正式通过媒体 → 布设周期 → 机位 → 位点及回收维护关联；批次不能代替 deployment_id。当前不虚构工作组、项目、区域或正式外键。 |
| 拍摄日期、拍摄时间 | 保留原始拍摄信息。Excel 历史来源需与正式媒体匹配后确认，不能覆盖首次冻结的 captured_at 或擅自确定来源时区。 |
| 校正后拍摄日期、日期可能有误 | 保留原日期和日期级校正，查询日期优先采用校正日期，缺少时回退原日期。没有校正时刻，不伪造新的 time_corrected_at、时区或周期偏移；列表时刻仍为原值，日期变化时提示已校正。日期有误标记为空不等于已核实日期正确。 |
| 个体编号复核 | 已复核后的 individual_code 候选，最终应匹配稳定 individual.id，再形成 media_individual。相同媒体允许多行不同个体；同媒体同个体不能静默覆盖。当前不自动创建档案。 |
| 识别人 | media_individual.annotated_by，按原文保留；MY/QF 不凭分隔符擅自拆账号。 |
| 复核人、复核状态 | media_individual.reviewed_by、review_status。此次样例补 CS，状态为 reviewed；reviewed_at 缺失保持空。导入文件明确给出状态时以该状态为准，不能仅凭有复核人推断已复核。 |
| 复核备注、备注 | 分别保留原文，属于此次出现/复核的说明与源快照；不写入全局个体档案说明。 |
| 数量 | 整段视频中豹个体数量，不是这一行出现的数量。同媒体多行须一致，不对逐行数量求和，不据此计算独立个体数。 |
| 可识别性 | 1=可识别，2=不可识别，3=待识别。这是源观察状态，与复核状态、标注完成状态分开。 |
| 是否成年、性别 | 1=成年，2=未成年，3=无法确认；M=雄性，F=雌性，U=未知。是此次拍摄的观察，不自动反推出生年份、存活状态或覆盖 individual.sex。 |
| 角度、位置、受伤、行为、确信度 | 保留为此次识别的源观察，不变成 individual_profile 代表图或永久档案字段。多角度用“、”连接；确信度 A/B 不换算为百分比。 |
| 多只豹情况下的行为 | 1=育幼，2=兄弟姐妹，3=一公一母尾随，4=交配，5=未知关系同框；- 为不适用，空值不强填。显示释义、保留原码，不自动创建个体关系。 |
| 繁殖情况 | “否”或繁殖数量，作为源观察保留，不自动生成二期繁殖记录。 |
| 独立拍摄 | 表头明确“对同一只豹连续拍摄的首张照片标 1”，是此次来源的个体连续拍摄标记。仅个体独立拍摄筛选匹配 1；0/空值分别保留，不写入文件级 media.is_independent_capture 或物种级标记，不据此计算 RAI。 |
| 上一次拍摄时间 | 源表辅助计算值，00:00:00 仍保留。没有对应日期和媒体关系，不创建“上一次媒体”外键或独立事件。 |

`unknown_individual` 或空编号表示未知：投影为媒体未知个体标签，不建立虚拟档案，不计算未知个体身份数量。样例中的 `HSunknowncub2603F` 是表中给定的完整复核编号，不因包含英文 unknown 就改写为系统未知标签；正式建档或别名核验仍需专门流程。

数据库 V1.5 没有单独列出可识别性、此次成年观察、数量、角度等所有源字段。本版使用导入项源快照/after_data 的设计投影保留这些信息，不擅自新增正式数据库列。`databaseProjection()` 是字段解释用的结构化投影，不是可直接执行的 SQL 载荷，也未将字符串编号伪装成已核实的数据库外键。

## 页面与交互

- 导航 → 标题与导入/下载 → 筛选 → 识别记录。桌面主筛选五列，关键词占两列；平板三列、手机两列，与 module02 保持一致。
- 主筛选为个体编号、位点、相机编号、回收批次、拍摄时间、关键词、识别人、复核人、复核状态。“更多筛选”包含可识别性、是否成年、角度、性别、确信度，使用中文释义筛选，原值保留。日期范围采用校正日期优先的查询口径。
- 记录标题下的编号筛选项按当前基础筛选范围计数，数字是记录条数；点击可进一步筛选，再次点击或清除取消。顶部条件变更时取消该进一步筛选，不把标签数量当作动物数量。未构造无来源的区域/小地名/项目关系。
- 表格保留分页、拍摄时间排序、跨页勾选与固定操作列，重点展示媒体、个体和复核信息；工具栏使用“仅个体独立拍摄”。
- 详情按“个体出现与复核、媒体信息、识别观察、时间校正与来源”组织。编码显示释义，可悬停查看原值；原始路径可复制，单条可下载。
- 导入为选择/拖拽 → 首表预检 → 确认 → 实际结果，支持 .xls/.xlsx、20 MB。兼容新版附件中的全部说明性长表头及简洁标准表头，保留 Excel 行号；忽略全空行，错误阻止整批写入。复核人缺失或为空时默认 CS；“个体编号复核”表头且未提供复核状态时按已复核读取，普通“个体编号”表头缺状态时为未复核，显式状态优先。不通过重复编号强行覆盖更正。
- 下载支持全部、当前筛选结果、跨页已选或单条。真实 .xlsx 包含全部 26 个源字段，加复核人、复核状态，共 28 列；编码、空值、日期与 00:00:00 保持原值。另有“字段说明”工作表，解释编码和查询口径。模板使用同一字段结构。

## 原型边界

当前独立原型在浏览器读取和保存，未接正式数据库、个体档案、NAS 媒体服务或工作组权限。前一版 localStorage 保持原样，新结构使用专用存储键 `wildlifedata-module03-reviewed-202606-v2`，不读取或混入旧的 262 条样例；新版后续导入仍刷新保留。

完整相同行跳过。有编号时按包含路径、文件名、相机、位点、批次的媒体上下文及编号识别冲突；同媒体多个编号分别保留，同媒体拍摄信息及视频数量不一致报错。内容或复核信息更改时阻止直接覆盖。正式数据库要求的媒体稳定 ID 匹配、缺失档案核验、逐媒体完整集合差异确认与替换、事务、前后快照和审计仍需服务端接入；当前不宣称已实现这些生产能力。

本版字段释义来自新附件的明确表头和既有数据库设计，不自动把本次观察扩展成永久档案。附件仅作为数据和字段语义来源，不作为操作指令。未修改用户维护的 guide 或数据库结构。
