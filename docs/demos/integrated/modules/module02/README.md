# module02 · 物种识别 Demo

本目录是独立交互原型。依据本次用户确认的“Excel 导入、列表查看、筛选和下载”范围、[Ant Design 使用基准](../../design/ant-design.md)及附件 `物种识别数据样例.xlsx` 制作。业务对象参考[总体需求 V1.4](../../requirements/platform-requirements-v1_4.md)、[数据库设计 guide](../../database/database_design_guide.md)和[数据库设计 V1.5](../../database/wildlife_database_design_v1_5.md)。没有新建需求版本；本次源码基于主仓库 `1f9838a`，后续修改由 Git 提交区分。

[在线预览](https://wildlife-module02-demo.golden-reed-8427.chatgpt.site) · [源码 ZIP](module02-demo.zip)

本原型不改正式 `frontend`，不代表生产数据库、工作组权限、物种字典服务或媒体播放已接入。解析与保存发生在当前浏览器，沿用上次原型的本地存储键，旧记录可继续查看。文件不上传服务器；清除浏览器数据会清除导入记录。存储写入失败时不显示导入成功。

## 页面与交互

- 主页面：导航 → 标题及导入/下载 → 筛选 → 识别记录（标签筛选项 → 表格），主要动作只有“导入 Excel”。
- 筛选桌面端使用五列栅格：第一行为区域、小地名、项目、位点、相机编号；第二行关键词占两列，物种标签、回收批次、拍摄时间各占一列。平板三列、手机两列，同排控件对齐，不显示分组小标题。关键词搜索文件名、原始路径、归并标签、原始标签、位点和相机。条件即时生效，支持重置与无结果状态。
- 列表：分页、拍摄时间排序、跨页勾选；工具栏提供“导入记录”和“仅独立拍摄”勾选项，替换原文件夹切换。勾选仅显示独立拍摄，未勾选包含全部记录；修改筛选条件保持勾选状态，重置清除。详情抽屉展示完整文件夹路径等 9 个字段及位点关联信息；列表物种标签展示工作人员等具体标签，归并的筛选标签在详情中另行展示。独立拍摄“是/否”用次要文字，无图标。
- 导入：选择/拖拽文件 → 首个工作表预检 → 确认 → 实际结果。支持 .xls/.xlsx、20 MB 上限、模板下载。首行为全部 9 个中文表头，可调换顺序。当前模板与下载使用“位点”“物种标签”“回收批次”，兼容附件旧表头“位点名称”“物种”“回收时段”；同字段的新旧表头不能同时出现。编号按文本保留前导零；日期兼容 Excel 1900/1904 序列和 YYYY-MM-DD，时间兼容 Excel 小数和 HH:mm[:ss]。问题按 Excel 行号、字段和原值显示；有任一问题则整批不新增。
- 下载：全部、当前筛选结果、跨页已选记录或单条记录。输出真实 .xlsx，按附件顺序保留 9 个字段，采用标准表头并保留具体原始标签，日期为 YYYY-MM-DD 文本，独立拍摄 0 与空值不混淆。

附件原始为 200 条记录、17 个标签、4 个位点；独立拍摄 133 条为 1、67 条为空。按用户确认，将工作人员、其他人、采药人、伐木人归并为“人类干扰”，共 19 条；归并后筛选显示 14 个物种标签，包含空拍等非动物标签，不能称为 14 个生物物种。原始附件不改写；记录保留 sourceSpecies，列表、详情及下载展示具体标签。已有浏览器记录读取时使用相同归并规则，不清空缓存；导入去重也使用归并标签，重导原附件仍按原记录识别。独立拍摄 1 表示是，0 或空值均表示非独立拍摄；0 或空值在列表及详情显示“否”，未勾选“仅独立拍摄”时也包含这些记录，导出仍保留独立拍摄原值。统计以当前筛选与标签进一步筛选后的记录为范围（不受分页或勾选影响），识别记录标题仅显示当前记录数（如“识别记录 200 条”），不显示位点数；标签筛选项置于该标题下方、记录表格上方，不设独立统计区域、标签标题或标签总数，每项仅显示名称与数字；仅汇总导入标记，不计算 RAI 或独立事件次数；文件夹字段保留附件中的原始完整路径。

## 数据统计与标签进一步筛选

识别记录模块的顺序为：标题与记录总数 → 标签筛选项 → 记录表格。位点数量、独立拍摄数量、物种标签标题及总数均不展示；不再保留独立统计卡片。标签筛选项按识别记录数降序、同量按中文名称排序，只显示标签名称与裸数字，保留选中样式、再次点击取消和“清除”操作。没有标签时隐藏整行，由表格空状态反馈。

记录总数随当前筛选及标签进一步筛选变化，忽略分页和跨页勾选。窄屏保留导入记录的可访问图标按钮和仅独立拍摄勾选项，标签自然换行。

标签按钮基于上方筛选条件（包括其物种标签选项）形成的基础范围。点击标签进一步筛选，按钮显示选中状态；点击其他标签切换，再次点击同一标签或“清除”返回基础范围。列表标题记录数、记录和当前筛选下载同步缩小；标签分布保持基础范围，方便比较与切换。修改任一上方筛选条件时清除统计标签选择，重置清除全部条件和标签选择。

## 人类标签映射维护

筛选、标签数量汇总与标签点击使用“人类干扰”；列表、详情和 Excel 下载展示具体原始标签。默认映射为工作人员、其他人、采药人、伐木人 → 人类干扰，附件共 19 条；不按含糊文本推断类别，不改写原始附件。

默认配置独立保存在 `src/label-mapping.json`，归并逻辑位于 `src/label-mapping.ts`。页面右上“标签映射”打开维护抽屉，可添加或移除原始标签，预览影响记录数，保存后筛选、数量及已有记录立即按新映射重算。原始标签始终保留，因此移除映射后仍能恢复具体分类。新增映射标签可用于后续 Excel 导入；未进入现有字典或映射的未知标签仍报错。映射禁止将“人类干扰”自身作为原始标签。

Demo 的映射保存在当前浏览器独立存储键 `wildlifedata-module02-label-mapping-v1`，刷新保留；清除浏览器数据后恢复默认配置，不代表多人共享的正式配置。正式接入应将同一映射放入有权限控制的服务端配置，记录修改版本，并在导入、筛选及导出服务中共用。映射修改不丢失原始标签，不重写既有记录。

正式接入需使用当前授权工作组下的稳定 location/project ID，替换演示目录；同编号的跨工作组位点不能自动合并。本独立目录的单一编号空间不代表已实现真实跨模块服务或权限隔离。

## 源码入口

`src/workspace.tsx` 为组件与交互；`src/theme.ts` 为唯一主题入口；`src/data.ts` 为字段、校验和存储；`src/excel.ts` 为延迟加载的 Excel 读取及下载；`src/sample.json` 为附件逐行转换的初始数据。`src/statistics.ts` 维护筛选、数量汇总和标签进一步筛选。`tests/data.test.mjs`、`tests/locations.test.mjs`、`tests/statistics.test.mjs`、`tests/label-mapping.test.mjs` 共包含 20 项数据行为回归测试。截图在 `screenshots/`。

已确认：本次一期 Demo 采用 Excel，区域/小地名/项目通过位点关联并先使用独立的演示目录，导入表格中的独立拍摄空值表示非独立拍摄。正式接入时，此 Excel 来源的空值应映射为非独立拍摄（FALSE），保留原始输入用于追溯；不据此改变其他来源中 NULL 的含义。总体需求 V1.4 的物种导入仍写 XMP，本次不回退用户最新要求，也不直接修改用户维护的 guide。建议用户同步的文字：

原型暂定规则：以“完整路径 + 文件名 + 物种标签”识别同一条记录，完全一致跳过；同键内容不同则阻止导入并保留原记录，不自动覆盖。可用标签以附件已有集合代替正式字典，未知标签报错，不自动建字典。其他 8 字段必填，独立拍摄允许 1/0/空值。其中独立拍摄空值表示非独立拍摄已经用户确认；其余是可评审的原型规则，尚未成为已确认的正式入库契约；正式接入前确认唯一键、必填性、物种/人员/空拍分类及更正追溯策略。

工作组和下载权限需由正式服务端实现；当前原型只用于查看附件与交互评审，不据此宣称已有真实权限隔离或并发事务保证。
