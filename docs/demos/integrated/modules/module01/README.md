# 相机位点管理 Demo

以已确认的四类表单字段及用户最新要求为依据，使用 React / Ant Design 构建独立浏览器演示。本版为用户确认后同步 GitHub 的云端审阅源码。用户维护的 guide 不直接改写。

## 页面与高频路径

- **位点列表**：搜索编号、别名或小地名，按区域、小地名、项目和当前启用状态筛选。右上角固定“新建位点 / 批量导入”；行内“新增记录”进入该位点的操作表单。位置单行展示区域与小地名，并单列项目；勾选后可导出坐标、轨迹、照片。
- **位点详情**：默认查看精简的操作记录，突出操作类型、现场相机状态、异常和实际动作。只读记录中的相机型号、条形码、参数仅在安装记录中展示；新增/修改操作的表单始终展示相机信息，沿用已确认的表单规则。
- **低频资料**：侧栏摘要通过左下角“查看全部”进入独立完整信息页，按布设、地理、现场资料、生境调查分区，直接展示最新调查结果；历史调查在抽屉中查看。新增/修改明确进入表单，保存或取消返回来源页面。
- **新增操作**：从列表行“新增记录”或详情页“新增操作”直接进入对应位点。有在位相机时默认检查，否则默认安装；单台在位时带入机位，操作日期带入当天，记录人员带入当前演示账号，现场状态仍须填写。
- **操作表单的相机信息**：安装时填写型号、条形码和默认拍摄参数；检查和撤回带入上次信息并默认只读；检查勾选更换相机/丢失后补装可编辑型号与条形码，勾选调整参数可编辑拍摄参数，取消动作后恢复原值。
- **新建位点**：填写位点信息后进入首次安装，提交后回到列表。两步均支持“填入演示数据”，只填表，不自动提交，编号避开已有记录。

当前在位数量、对拍/单侧及启用/停用只显示北京时间当天的结果，不提供历史状态日期切换。未来操作不提前改变当前状态；表单内的操作日期仍是业务记录字段。

## 自动周期

安装开启周期；检查结束上一周期并在相机仍在位时开启下一周期；撤回或丢失未补装结束当前周期而不再开启。周期不提供独立新增入口，也不能手工改起止日期。

周期列表是低频入口，可查看进行中/已结束周期。已结束周期可补充多段故障和时间校准；边界由起止操作决定。安装/检查/撤回修改后按稳定操作 ID 同步周期，保留已有故障和校准；故障段超出新边界时标记需核对，不静默清空。

旧浏览器周期仅在位点、相机、日期可唯一匹配时迁移到操作关联；无法匹配的旧记录保留为待核对、只读记录，不丢弃原事实。操作、自动周期和相关审计写入同一份 localStorage 账本，写入失败保留输入且不更新内存业务状态；原独立数组保留作兼容镜像，以账本为准。

## 示例与导出

首次打开自动补充 DEMO-701～704 四个虚构位点及额外 25 个位点，主要情形涵盖对拍、单侧、撤回和故障，包含调查、操作、周期、KML 示例轨迹及 SVG 位点示意图；不覆盖同编号的已有位点。示例坐标和图示不代表真实监测点。示例 DEMO-701 的别名为 L01，其余示例无别名；已有演示记录按 ID 一次迁移，自建位点别名保留。

导出坐标可选 KML/KMZ，轨迹、照片按原文件名和内容打包 ZIP；重复文件名使用序号子目录区分。KML 是地理标记 XML，KMZ 为包含 `doc.kml` 的压缩包。支持时调用系统保存位置选择器，否则走浏览器下载。

## Excel 批量导入

列表右上角“批量导入”下拉选择“导入位点”或“导入操作记录”，下载对应 Excel 模板，在数据工作表填写后上传 `.xlsx`，先逐行预校验，再确认整批导入。支持最多 1000 条 / 10MB；错误文件不写入有效行，保留行号和具体原因。工作簿“填写说明”列出必填、条件字段、选项及重复规则，不作为数据导入。

- 位点按工作组内编号判重，不覆盖已有编号；编号和网格保留前导零，项目用“、”等分隔符多选。附件在位点资料中另行上传。
- 操作的位点须已存在。同位点、相机、操作日期、操作类型为同键冲突，须核对，不覆盖；本批按日期和原始行顺序处理，先前安装信息可供本批后续检查/撤回引用。
- 相机信息的填写、只读沿用和更换/调整的条件与操作表单一致。导入操作后，操作、自动周期和批次审计一起写入浏览器账本。
- 提交前重新读取当前记录并复验。预校验后数据变化则要求重新校验；保存失败保留文件和预校验结果，可重试。此为本浏览器演示，不代表正式后端权限或跨客户端事务已实现。
- 只读取模板数据工作表；公式/错误值拒绝导入，日期使用 YYYY-MM-DD，旧 `.xls` 请另存为 `.xlsx`。

## 运行和交付

源码 ZIP 内的 `demo.html` 是单文件演示，也可用开发服务器：

```bash
npm ci
npm run dev
npm test
npm run package
```

打包输出 `release/module01-demo.html` 及 `module01-demo.zip`，包含同一份源码、测试、构建结果与独立 HTML，不包含用户填写的数据或托管凭据。沿用 React 18 / antd 5 原型组合，正式应用框架升级独立实施。

浏览器检查（另起静态服务器）：

```bash
python -m http.server 8768 --directory dist
DEMO_URL=http://localhost:8768 CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

未指定 `CHROMIUM_PATH` 时使用 Playwright 自带浏览器，首次可 `npx playwright install chromium`。截图与测试下载写入忽略的 `work/browser-check/`。

## 边界与源码

数据只在当前浏览器，记录存 localStorage，文件存 IndexedDB；工作组固定山西、账号为 demo-user。清除浏览器数据或更换来源会改变这份演示数据。未接入正式权限、数据库或真实媒体；文件与业务记录跨存储的事务不等同于正式后端事务。

- `src/manager.jsx`：列表、快速新增、导出与编辑页面调度。
- `src/import-dialog.jsx`、`import-data.js`、`excel.js`：导入交互、字段校验、模板与 Excel 读取。
- `src/detail.jsx`：操作/周期列表及低频资料抽屉。
- `src/engine.js`：已确认表单、校验与保存。
- `src/cycles.js`：基于操作 ID 自动生成周期、迁移旧记录及保留事实。
- `src/site-state.js` / `current-date.js`：当前在位状态与北京时间日期更新。
- `src/samples.js`、`files.js`、`export.js`：示例、附件与下载。

验证覆盖自动周期、修改边界保留故障、丢失/撤回、当前状态、示例不覆盖、KML/KMZ；浏览器覆盖高频入口、表单相机信息与条件编辑、故障校准、保存失败原子性、新建两步流程、刷新保留与窄屏布局。

导入验证覆盖真实 XLSX 模板下载与上传、整批错误阻断、重复键、前导零、多项目、同批先安装后检查、自动周期、预校验后变更复验及存储失败重试。测试文件与截图在忽略的 `work/import-check/`。

## 位点列表与删除

列表位置单行显示“区域 - 小地名”，不显示网格；当前状态不显示在位台数。筛选顺序为区域、小地名、项目、状态；支持小地名和项目组合筛选，桌面各列按比例随容器宽度变化，手机使用卡片。项目最多展示两个名称，其他以数量提示；完整关联不被截断。演示小地名为上北舍、马坊乡、横岭，含 X337道路监测等多项目，701 别名为 L01；移除旧 901，填充新位点从 705 起。

详情右上角“更多位点操作 → 删除位点”二次确认后移出列表，保留操作、自动周期、调查和附件，不生成现场撤机事实，编号不再复用。删除后禁止新增记录和操作导入；存储失败保留原记录并支持重试。此为浏览器软删除，尚未接正式后端。

浏览器验证另覆盖旧演示数据迁移、组合筛选、项目展示上限、列宽比例，以及删除取消、失败重试、刷新保留和历史附件保留。

操作批次的演示值和输入提示为 `202610`；批次仍可自由输入或从近期值选择。

列表每页 10 条，使用紧凑行高；整行（手机整张卡片）可点击或聚焦后按 Enter 进入详情，保留独立勾选和新增记录，移除详情按钮。首次补充 25 个演示位点（默认总计 29 个），多数为单项目，仅少数为多项目；刷新不重复补充、不会恢复已删除位点。

列表与 module02 共用设计层次：页面标题与主要操作、独立筛选条件卡片、带数量及导出入口的记录卡片；桌面五列带标签筛选，窄屏重排。采用共享的中英文字号分级与紧凑表格，分页展示总数和当前范围。

## 列表视觉与交互规范

位点、操作记录、布设周期和调查列表共用 `src/list-ui.jsx`：中文正文 13px，纯英文编号/日期 14px（等宽数字），次要说明及标签 12px；表头 13px/600，行距 20px，单元格上下留白 8px。不同字符的尺寸只用于补偿视觉差异，重要性通过信息位置与颜色表达，不把整行放大或加粗。手机保持相同字号。

所有列表每页 10 条；筛选即时生效并回第一页，重置清空条件。整行或整卡点击、聚焦后 Enter/空格查看；勾选和独立操作按钮不触发行跳转。位点打开详情页，操作/周期/调查打开只读抽屉；明确点击修改或补充后才编辑，关闭抽屉保留所在列表。调查详情支持返回调查列表。空列表说明无记录，筛选无结果可重置；危险操作确认并保留失败重试。选择数量明确展示、支持取消选择。

批次演示统一为 `202610`，包括演示记录、输入提示、近期建议及已识别旧演示值迁移，不将自有批次改成固定值。跨模块规范见项目 `docs/design/list-ui-guidelines.md`；本次应用于 module01，module02 沿用其已有数字内容的视觉基准。

位点详情保留操作记录/布设周期主区域，右侧信息按“布设信息 → 地理信息 → 现场资料 → 生境调查”组织；布设和地理信息优先展示，现场资料仅显示轨迹/照片数量，调查仅显示最近日期。左下角仅一个“查看全部”入口，打开独立的完整信息页。

完整信息页参考新建位点，分布设信息、地理信息、现场资料、生境调查四个模块，最新调查结果直接展开；支持调查历史和新增调查。修改/新增保存或取消后返回完整信息页；返回位点详情保留操作筛选和标签页。窄屏信息栏移到主区域下方。
