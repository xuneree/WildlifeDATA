# 相机位点管理 Demo

已确认的浏览器交互原型，包含位点信息、生境调查、操作记录和自动布设周期。基于 React 18 / Ant Design 5，工作组固定山西；数据保存在当前浏览器，尚未接入正式权限、数据库或媒体服务。

[三模块公开体验](https://wildlife-integrated-demo.golden-reed-8427.chatgpt.site/#/camera) · [独立审阅预览](https://wildlife-camera-review-20261111.golden-reed-8427.chatgpt.site) · [源码与单文件演示包](https://wildlife-integrated-demo.golden-reed-8427.chatgpt.site/downloads/module01-demo.zip)

## 运行与交付

```bash
npm ci
npm test
npm run build
npm run package
```

源码包包含源码、锁文件、测试、构建结果和可直接打开的 `demo.html`。构建后的 `dist/` 也可通过静态服务器访问。浏览器检查需在另一终端启动服务器：

## 页面与记录

- 位点列表：区域、小地名、项目、关键词、状态组合筛选；紧凑分页，每页10条。整行／手机卡片及键盘可进入详情，勾选与新增记录独立响应。返回列表保留筛选和分页。
- 位点详情：左上角返回；名称后仅显示启用状态和布设模式。主区域为操作记录／布设周期，相机下拉框位于页签右侧并统一筛选，不显示单独标签、重置按钮或操作类型筛选。
- 低频资料：侧栏展示布设、地理、附件数量和最近调查摘要；“查看全部”进入完整信息页，依次展示布设、地理、现场资料、最新生境调查，并提供调查历史及新增入口。
- 新建位点：先填位点，再登记首次安装；提交后返回列表，首条显示新增位点。“填入演示数据”只填表，不自动提交。
- 新增／修改操作：标题统一为“新增操作记录”／“修改操作记录”，左上角返回位点详情，不再重复路径、地名副标题和表单标题。保存或取消返回来源页面。

## 当前字段与条件规则

依据原始附件 `docs/source/红外相机监测野外记录表V4.2.docx` 和用户后续确认；已确认的新规则优先于旧 guide 与需求中的冲突描述。

- 经纬度采用 WGS84 十进制度，输入、保存、详情、Excel 导入及 KML/KMZ 坐标导出均保留6位小数，超出部分四舍五入、不足补零。轨迹原文件不转换。
- 位点、生境调查和操作记录的“记录人员”均选填，紧跟设置／调查／操作人员。
- 植被按乔木、灌木、草本分三行，沿用四等分列宽，行末留空；草本顺序为高度、盖度、类型。动物痕迹的物种名称占四分之一宽，其余展示痕迹多选。
- 动物痕迹和人为干扰共用调查日期，不重复填写发现日期。动物痕迹为可重复的物种／痕迹行；人为干扰为类型多选及其他说明；各调查分区可标记“未调查”。
- 相机支持照片、视频、照片+视频；连拍张数1/2/3/5；拍摄间隔以秒记录；参数区固定展示“侧边PIR是否打开（A323型号相机）”及是／否；A323可编辑，其他型号不要求填写。型号必填，条形码选填。
- 现场状态为正常、关机、损坏、丢失、倒了、其他。设置与拍摄情况为无问题、空拍多、电池没电、相机设置有误、触发异常、其他；“无问题”与异常选项互斥，设置有误、触发异常、其他状态／情况填写相应说明。
- 检查动作包括收卡换卡、更换电池、调整角度、更换相机、丢失重补、移动位置、参数调整、其他。更换／补装可编辑设备信息，参数调整可编辑拍摄配置，取消动作后恢复此前信息。
- 安装填写初始设备与配置；检查、撤回带入此前信息并默认只读。撤回填写原因，不填检查动作；检查备注在操作内容中。旧分钟间隔按原值乘60迁移为秒，不把已有实际间隔改成新默认值。
- 附件删除线标记的诱饵、胸径、树种、时分以及维护表中的“豹和人为干扰”未加入字段。

## 周期、状态与删除

安装开启周期；检查结束上一周期并在相机仍在位时开启下一周期；撤回或丢失未补装结束周期。周期不能独立新增或手工修改边界；已结束周期可补充多段故障及时间校准。故障段不能重叠且须位于周期内；时间点按北京时间解释。

状态仅展示北京时间当天的已记录事实：0台停用、1台单侧、2台对拍；故障和关机仍算在位，超过2台标记待核查。未来操作不提前改变状态，数据回收不等同撤机。

操作记录列表和手机卡片不显示删除按钮，点击记录进入详情抽屉后可删除；列表摘要不显示“无问题”，异常信息仍正常显示。确认框展示对象和影响，删除与周期重算、审计一起写入账本；失败保留原记录并支持重试。起始操作已删除的空周期移除；已填写故障、校准的周期保留为待核对记录。审计保存原操作和关联周期快照，旧编辑页不能恢复已删操作。

位点通过详情“更多位点操作”删除，保留全部操作、周期、调查、附件及审计，不代表现场撤机，编号不再复用；删除位点不能再接收新增／导入操作。

## 示例、导入和导出

默认29个位点，涵盖对拍、单侧、撤回和故障。DEMO-701 无别名、只关联一个项目，12条记录按10＋2分页；DEMO-801 展示别名L01。批次从202610按两个月向前倒排到202512，日期为对应月份1日，同一相机同一批次仅一条内置操作；日期下方显示“批次：202610”。首次布设与周期同步。迁移只更新内置示例，不覆盖自有位点和新增操作，刷新不恢复已删除记录。

列表可勾选导出坐标、轨迹、照片，多项按位点打包ZIP；坐标可选KML/KMZ，轨迹和照片保持原文件。支持的浏览器允许用户选择保存位置。

Excel导入支持位点和操作记录：模板下载、真实XLSX读取、条件字段预校验、重复与引用校验、整批提交和提交前复验；每批最多1000条／10MB，任何行错误都不写入有效行。编号保留前导零，日期为YYYY-MM-DD，多选用顿号分隔。不同批次不覆盖已有记录；操作导入同步周期及审计。
